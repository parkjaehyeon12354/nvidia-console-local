## 1. 받기와 실행

1. [릴리스 페이지](https://github.com/parkjaehyeon12354/zako-code/releases/latest) 에서 `ZakoCode.exe` 를 받습니다.
2. 바탕화면이나 다운로드 폴더에 두고 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 서명하지 않은 프로그램이라 뜨는 경고입니다.

`Program Files` 처럼 쓰기 권한이 없는 폴더에 두면 자동 업데이트가 파일을 바꾸지 못합니다.

## 2. 처음 설정

왼쪽 아래 **⚙ 설정**을 누릅니다. **API 키** 칸에서 두 칸을 채웁니다. **둘 다 넣어야 동작합니다.**

| 칸 | 넣을 것 |
|---|---|
| API 키 | [build.nvidia.com](https://build.nvidia.com) 에 로그인해 발급받은 키. 설정의 **키 발급받기** 버튼이 그 페이지를 엽니다 |
| 보낼 곳 (Base URL) | NVIDIA 는 `https://integrate.api.nvidia.com/v1`. OpenAI 호환 주소면 다른 곳도 됩니다 |

- **키 보기**를 누르면 가려진 키를 확인할 수 있습니다. 붙여넣다 틀린 곳을 찾을 때 씁니다.
- 설정 창은 **✕**, **Esc**, 또는 창 바깥을 누르면 닫히고, 닫을 때 저장됩니다.

## 3. 대화하기

1. 입력칸 아래 **모델 이름**을 눌러 쓸 모델을 고릅니다.
2. 입력칸에 하고 싶은 걸 적고 **Enter** 를 누릅니다. 줄을 바꾸려면 **Shift+Enter** 입니다.
3. 답변에 코드가 있으면 아래에 **복사** 버튼이 생깁니다. HTML 코드면 **브라우저로 열기** 버튼도 같이 나옵니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 새 대화 | 왼쪽 위 **＋ 새 대화** |
| 지난 대화 보기 | 왼쪽 목록에서 누르기 |
| 대화 지우기 | 목록의 그 줄에 마우스를 올려 오른쪽 끝 **×**, 또는 Delete 키 |

## 4. 사용량 화면

새 대화를 열면 사용량이 나옵니다.

- **개요**: 세션·메시지·토큰 수, 활성 일수, 연속 사용 일수, 가장 많이 쓴 시간대, 즐겨 쓴 모델, 날짜별 사용 기록
- **모델**: 모델별로 쓴 양
- 오른쪽 위에서 **전체 / 30일 / 7d**로 기간을 바꿉니다.

토큰은 서버가 알려준 값만 셉니다. 사용량 기능이 생기기 전에 한 대화는 0 으로 나옵니다.

## 5. 업데이트

켤 때 새 버전을 확인해서 미리 받아 둡니다. 준비되면 위쪽에 업데이트 버튼이 뜨고, 누르면 바꾼 뒤 다시 켜집니다. 직접 확인하려면 **설정 → 정보 → 업데이트 확인**을 누릅니다.

2.x 버전을 쓰고 있었다면 자동으로 넘어오지 않습니다. 릴리스 페이지에서 한 번 직접 받아 바꿔 주세요.

## 6. 저장 위치와 초기화

EXE 옆에는 아무 파일도 만들지 않습니다. 모두 `%LOCALAPPDATA%\ZakoCode` 에 저장됩니다. **설정 → 저장 위치 → 폴더 열기**로 열 수 있습니다.

| 파일 | 내용 |
|---|---|
| `chats.json` | 대화 내역 |
| `key.dat` | API 키. Windows 계정에 묶어 암호화해서 다른 계정이나 다른 PC 에서는 풀리지 않습니다 |
| `root.txt` | 보낼 곳(Base URL) |

프로그램을 끈 뒤 파일을 지우면 그 부분이 초기화됩니다. 대화는 이 PC 에만 있고 다른 기기와 동기화되지 않습니다.

## 7. 폰에서 쓰기

폰에서는 AI 가 명령을 직접 실행하며 일하는 방식으로 씁니다. AI 가 명령을 내면 실행할지 먼저 묻습니다.

| 폰 | 쓰는 것 | 설명 |
|---|---|---|
| 갤럭시 | Zako Code 앱 + Termux | [zako-code-android](https://github.com/parkjaehyeon12354/zako-code-android) |
| 아이폰 | iSH 터미널에서 `zako.py` | [README 의 폰에서 항목](../README.md#폰에서-갤럭시아이폰) |

폰에서도 API 키와 보낼 곳을 한 번 더 넣어야 합니다. PC 의 키 파일은 옮겨지지 않습니다.

## 8. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 보내도 설정 창이 열림 | API 키와 보낼 곳을 둘 다 넣었는지 |
| 모델 목록이 안 나옴 | 키에 오타가 없는지(**키 보기**), 보낼 곳 주소가 `/v1` 까지 맞는지 |
| 서버 오류 401 | 키가 틀렸거나 만료됨. 새로 발급받아 넣기 |
| 서버 오류 404 | 모델 이름이나 보낼 곳 주소가 틀림 |
| 업데이트가 안 됨 | EXE 가 `Program Files` 같은 쓰기 금지 폴더에 있는지 |
| 대화가 사라짐 | 다른 Windows 계정이나 다른 PC 인지. 기록은 PC·계정마다 따로입니다 |

해결이 안 되면 [이슈](https://github.com/parkjaehyeon12354/zako-code/issues) 에 남겨 주세요.
