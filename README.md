# NVIDIA 코딩 콘솔 (로컬판)

서버도 계정도 없이 **이 PC 안에서만** 도는 데스크톱 앱입니다. NVIDIA API 키만 있으면 됩니다.

```
app/   EXE 소스 (창 + 로컬 서버)
web/   웹사이트 — EXE 와 따로 둡니다. 고치고 EXE 를 다시 켜면 그대로 반영됩니다.
```

## 쓰는 법

1. `NvidiaConsole.exe` 를 실행합니다. 같은 폴더에 `web` 폴더가 있어야 합니다.
2. 왼쪽 아래에 NVIDIA API 키를 넣습니다. 키는 [build.nvidia.com](https://build.nvidia.com) 에서 발급받습니다.
3. 모델을 고르고 질문하면 됩니다.

- 로그인이 없습니다. **대화는 이 PC 에만** 남고 다른 기기와 동기화되지 않습니다.
- 키와 대화는 EXE 옆 `NvidiaConsole.WebView2` 폴더(브라우저 프로필)에 저장됩니다. 폴더째 지우면 초기화됩니다.
- 실행하려면 **.NET 10 데스크톱 런타임**과 **WebView2 런타임**이 필요합니다. 둘 다 최신 Windows 에는 대개 이미 있습니다.

## 어떻게 도는가

EXE 가 켜지면 옆의 `web` 폴더를 `127.0.0.1` 의 빈 포트로 띄우고, 그 페이지를 창 안 WebView2 로 엽니다.
NVIDIA 호출(`/v1/*`)도 같은 로컬 서버가 중계합니다 — 브라우저에서 NVIDIA 를 직접 부르면 CORS 에 막히기 때문입니다.

- 서버는 `127.0.0.1` 에만 바인딩해서 같은 네트워크의 다른 PC 에서는 접근할 수 없습니다.
- 중계기는 키를 보관하지 않습니다. 페이지가 보낸 인증 헤더를 그대로 넘길 뿐입니다.
- `web` 폴더 밖을 가리키는 경로 요청은 거절합니다.

## 빌드

확인·디버깅용으로 환경 변수 `NVIDIA_CONSOLE_PORT` 를 주면 로컬 서버가 그 포트로 뜹니다. 평소에는 임의의 빈 포트를 씁니다.

```
cd app
dotnet publish -c Release
```

`app\dist\` 에 `NvidiaConsole.exe` 와 `web\` 가 함께 나옵니다. 그 폴더를 통째로 옮기면 다른 PC 에서도 돌아갑니다.
